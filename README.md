## 🧩 Atualização da Cruzadinha — GO!RN 26

Este projeto consiste na **atualização e adaptação de uma cruzadinha desenvolvida anteriormente por alunos da UFERSA**, que já foi utilizada em eventos como a SESITEC e o GO!RN 25.

A cruzadinha não é um projeto desenvolvido pela equipe responsável por esta atualização. O objetivo é **aproveitar o projeto existente e realizar as modificações necessárias para que ele possa ser utilizado durante o GO!RN 26**, preservando sua proposta original e aprimorando sua experiência de uso.

A versão atual é uma aplicação web desenvolvida utilizando **HTML, CSS e JavaScript**, com um sistema de preenchimento de palavras por meio de letras disponibilizadas ao participante e verificação automática das respostas.

### 🎯 Objetivo da atualização

Adaptar a cruzadinha existente para o contexto do **GO!RN 26**, realizando as alterações necessárias em seu conteúdo, identidade visual e funcionamento, sem descaracterizar a proposta original do projeto.
